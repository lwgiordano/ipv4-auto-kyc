# stop-slop

Rewrite the target text to remove predictable AI writing patterns while keeping
its meaning, facts, proper nouns, numbers, links, and code exactly. This is a
style edit, not a rewrite of substance. Shorter and plainer almost always wins;
do not replace old filler with new filler.

## Cut these on sight

**Filler openers and hedges**
- "It's worth noting that", "It's important to note", "It should be noted", "Keep in mind that"
- "At its core", "When it comes to", "In today's fast-paced world", "In the world of X"
- Reflexive "arguably", "generally", "typically", "often" that soften a plain claim

**Empty connectives** — delete, or replace with a plain and/but/so:
- "Moreover", "Furthermore", "Additionally", "That said", "Notably", "Importantly",
  "Ultimately", "In essence", "Essentially", "Crucially"

**Corporate / marketing vocabulary** — replace with plain words:
- leverage → use, utilize → use, facilitate → help, foster → build,
  harness → use, streamline → simplify, robust/powerful/comprehensive → be specific,
  seamless(ly) → delete or be specific
- Banned flourishes: delve, dive into, unlock, elevate, tapestry, realm,
  landscape (figurative), testament to, beacon, navigate (figurative), embark,
  journey (figurative), spearhead

**Formulaic constructions**
- "Not just X, but Y" / "It's not about X; it's about Y"
- "Not only… but also"
- "Whether you're X or Y"
- Reflexive rule-of-three triads ("fast, reliable, and scalable") — keep only if each item earns its place
- "By [verb]-ing, you can…" used as a repeated sentence template

**Meta-commentary**
- "This section will…", "In this document…", "As mentioned earlier", "Let's explore / dive in"
- Closing "In conclusion / In summary / Overall" paragraphs that restate what was already said — delete

**Punctuation and rhythm tells**
- Em-dash overuse for dramatic asides — use them sparingly; prefer a comma, period, or parentheses
- Every bullet opening with a bolded lead-in on the same template — vary it
- Uniform sentence length and structure — vary it

## How to apply

1. Preserve meaning, facts, names, numbers, code, and links exactly.
2. Delete first, replace second — most tells can simply be cut.
3. Prefer the plainest accurate wording a knowledgeable human would use.
4. Keep the author's real voice and any deliberate emphasis; don't flatten everything into one register.
5. Final check: would a sharp editor leave this word? If not, cut it.

## Output

Edit the text in place (or return the revised text). If any change was
non-obvious, name the categories you cut in one short line — don't narrate
every edit.
